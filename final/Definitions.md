____________

| **Term**                                | **Definition**                                                                                                                             |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **Function Creep**                      | When a function asks "*What the hell am I doing here?... I dont belong here*" because you're using it for something it wasn't designed for |
| **Reactive password checking**          | System periodically runs its own password cracker to find guessable passwords                                                              |
| **Transferability**                     | B cannot **reuse** a successful authentication of A to impersonate A to C (kina like reply attack).                                        |
| **Impersonation**                       | The probability that another party C playing the role of A can cause B to accept, is negligible                                            |
| **closed policy**                       | only allows accesses that are specifically authorized                                                                                      |
| **open policy**                         | allows all accesses except those expressly prohibited policy combinations, conflict resolution.                                            |
| **Access Control Policy**               | Decides which subject can perform what operations on which object                                                                          |
| **Protection state of system**          | Describes current settings, values of system relevant to protection                                                                        |
| **Extended access control matrix**      | Matrix describing rights of subjects                                                                                                       |
| **Classification creep (BLP)**          | A subject can only be “editing” (reading and writing) a file at one security level while also viewing files at the same or lower levels.   |
| **covert channel**                      | is a sneaky way to transmit information using **shared resources** that aren't meant for communication.                                    |
| **Invoke**                              | Communication between objects                                                                                                              |
| **Sanitized data**                      | data that can be derived from corporate data but don’t reveal corporation’s identity.                                                      |
| **Attestation**                             | Prove to remote server what software is running on my machine.                                                                             |
| **Secure boot**                             | Method to “authorize” software                                                                                                             |
| **Platform Configuration Registers (PCRs)** | On a TPM, these are protected memory registers                                                                                             |
| **Quote**                                   | The Quote is a digital signature covering the verifier’s nonce and the current measurement aggregates stored in the PCRs.                  |
